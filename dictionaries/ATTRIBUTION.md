# Dictionary attribution

`en.txt` (generated by `tools/build_dictionary.py`) is derived from the
English word-frequency list in
[hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords),
which is built from the OpenSubtitles corpus (https://opus.nlpl.eu/).

- Content licence: CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/)
- Code licence of that repository: MIT

Changes made: lowercased, filtered to valid words, frequencies converted to a
log scale, truncated to the most frequent words. The generated `en.txt` is
shared under the same CC BY-SA 4.0 licence.
